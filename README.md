## Selected work

### 01 / Learning from physiological signals
**ECG Classification & Model Evaluation**

How much can a model learn from a 12-lead ECG—and how should that performance be evaluated? This project explores 1D residual networks, engineered signal features, and multimodal experiments, with an interactive Streamlit research dashboard.

- **Build:** signal preprocessing, TensorFlow models, LightGBM experiments, and prediction visualizations.
- **Evidence:** binary ROC-AUC of **0.9243**, recalculated from 2,000 saved predictions; internal validation, with assumptions and limitations documented.
- **Explore:** model comparisons, leakage audits, and the distinction between development results and independent evaluation.

[View project →](https://github.com/Pipe10101/deep-learning-project) · [Read the evidence →](https://github.com/Pipe10101/deep-learning-project/blob/main/docs/evidence.md)

### 02 / Modeling multi-sequence images
**SlotKnee-S · Knee MRI Classification**

A computer-vision pipeline that organizes MRI sequences into semantic slots and spatial anchors, then combines a DINOv2 encoder with finding-specific attention.

- **Build:** DICOM processing, PyTorch models, reusable image caches, and ensemble inference.
- **Investigate:** anchor sampling, knowledge distillation, and the tradeoff between model complexity and inference efficiency.
- **Explore:** training kernels, architectural choices, and tests for data loading, folds, and prediction workflows.

[View project →](https://github.com/Pipe10101/rsna-knee-detection.) · [Explore the model →](https://github.com/Pipe10101/rsna-knee-detection./blob/main/src/slotknee.py)

### 03 / Turning public data into useful workflows
**Opportunity Discovery & Skill-Gap Planning**

Two Python tools that collect public opportunities, rank them against a configurable skill profile, and turn task descriptions into learning resources and action plans.

- **Build:** API adapters, weighted keyword scoring, URL deduplication, and Markdown reports.
- **Approach:** transparent matching rules and reusable local outputs.
- **Explore:** the collection-to-report workflow and the separate skill-gap planning tool.

[View project →](https://github.com/Pipe10101/money-bot)
